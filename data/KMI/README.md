# KMI Dataset Directory Structure

This directory contains the KMI (Korean Mental health Interview) dataset files for the mind-eval evaluation framework.

## Directory Layout

```
data/KMI/
├── raw/
│   └── kmi.json                          # Original KMI dataset (1000 dialogues)
├── test/
│   ├── option_a_interactions_en.jsonl    # English utterances for evaluation
│   ├── option_b_interactions_ko.jsonl    # Korean utterances for evaluation
│   ├── option_c_interactions_ko.jsonl    # Korean utterances for evaluation
│   ├── option_a_judgments.jsonl          # Judgments: EN dialogue + EN prompts
│   ├── option_b_judgments.jsonl          # Judgments: KO dialogue + KO prompts
│   └── option_c_judgments.jsonl          # Judgments: KO dialogue + EN prompts
└── README.md                              # This file
```

## Data Flow

1. **Raw Data**: `raw/kmi.json` contains the original KMI dataset with bilingual dialogues
   - Each dialogue has both Korean (`utterance_ko`) and English (`utterance_en`) versions
   - Contains 1000 therapy dialogues with therapist-client interactions

2. **Converted Interactions**: `test/option_*_interactions_*.jsonl` files
   - Generated by `mindeval/scripts/convert_kmi.py`
   - Three variants for cross-lingual evaluation:
     - **Option A**: English utterances with English judgment prompts
     - **Option B**: Korean utterances with Korean judgment prompts  
     - **Option C**: Korean utterances with English judgment prompts
   - Each file contains dialogues in Mind-Eval format with member profiles

3. **Judgments**: `test/option_*_judgments.jsonl` files
   - Generated by `mindeval/scripts/generate_judgments.py`
   - Contains evaluation scores for five therapeutic criteria
   - Each option uses different language combinations for comparison

## File Formats

### Raw KMI Format (kmi.json)
```json
[
  {
    "id": 1,
    "category_ko": "정신건강",
    "category_en": "Mental Health",
    "dialogue": [
      {
        "role": "Therapist",
        "utterance_ko": "안녕하세요...",
        "utterance_en": "Hi...",
        "label": "Open Question"
      },
      {
        "role": "Client",
        "utterance_ko": "다른 사람들이...",
        "utterance_en": "I see other people..."
      }
    ]
  }
]
```

### Mind-Eval Interaction Format (option_*_interactions_*.jsonl)
```json
{
  "member_profile": {
    "name": "Anonymous",
    "sex": "Unknown",
    "age": 30,
    "race": "Asian",
    "region": "urban"
  },
  "interaction": [
    {"role": "assistant", "content": "안녕하세요..."},
    {"role": "user", "content": "다른 사람들이..."}
  ],
  "metadata": {
    "source": "KMI",
    "original_id": 1,
    "category": "Mental Health",
    "language": "ko",
    "option": "b",
    "profile_extracted": true
  }
}
```

## Usage

### Convert KMI Dataset
```bash
# Convert with profile extraction
python mindeval/scripts/convert_kmi.py \
    --input_path data/KMI/raw/kmi.json \
    --output_dir data/KMI/test \
    --extract_profile \
    --max_dialogues 100

# Convert without profile extraction (faster)
python mindeval/scripts/convert_kmi.py \
    --input_path data/KMI/raw/kmi.json \
    --output_dir data/KMI/test \
    --max_dialogues 1000
```

### Generate Judgments
```bash
# Option A: English dialogue + English prompts
python mindeval/scripts/generate_judgments.py \
    --interactions_path data/KMI/test/option_a_interactions_en.jsonl \
    --output_path data/KMI/test/option_a_judgments.jsonl

# Option B: Korean dialogue + Korean prompts
python mindeval/scripts/generate_judgments.py \
    --interactions_path data/KMI/test/option_b_interactions_ko.jsonl \
    --judge_template_path mindeval/judge_prompts_ko.py \
    --output_path data/KMI/test/option_b_judgments.jsonl

# Option C: Korean dialogue + English prompts
python mindeval/scripts/generate_judgments.py \
    --interactions_path data/KMI/test/option_c_interactions_ko.jsonl \
    --output_path data/KMI/test/option_c_judgments.jsonl
```

## Requirements Validation

This directory structure satisfies:
- **Requirement 8.3**: Output directory exists for JSONL files
- **Requirement 8.4**: Raw data file is accessible and readable
- **Requirement 1.8**: Three separate output files for each option
- **Requirement 4**: Mind-Eval format compliance

## Notes

- The `test/` directory will be populated by the conversion script
- Profile extraction is optional and can be disabled for faster processing
- All three options share the same extracted profiles for consistency
- Korean cultural context (race="Asian", region="urban") is applied to default profiles
